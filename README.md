# 🛒commerce-scraper(Python)

A high-performance, automated web scraper built with Python that extracts product details (Title, Price, Stock Status, and Links) from e-commerce platforms and exports them directly into a clean, structured Excel (`.xlsx`) spreadsheet.

---

### 🚀 Features
- **Multi-Page Scraping:** Automatically paginates through multiple catalog pages to collect massive datasets.
- **Data Cleaning:** Automatically parses and cleans raw HTML strings into structured numerical and text formats.
- **Direct Excel Export:** Uses `pandas` and `openpyxl` to generate ready-to-use spreadsheet reports without manual intervention.
- **Production-Ready:** Built with robust status-code checks and clean exception handling.

---

### 🧰 Tech Stack
* **Language:** Python 3.x
* **Core Libraries:** `requests`, `BeautifulSoup4` (bs4), `pandas`, `openpyxl`
